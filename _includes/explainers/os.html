Run the operating system's decisions yourself

3 simulators, each running the real algorithm: schedule processes on one CPU, replace pages in a small memory, and check whether granting resources is safe. Edit any number and every chart recomputes.

Algorithms as in Arpaci-Dusseau and Arpaci-Dusseau, Operating Systems: Three Easy Pieces, and Silberschatz, Galvin and Gagne, Operating System Concepts, whose reference string and Banker's example are the defaults here. Topic outline after OS & DBMS Foundation. scripts/verify_explainers.py checks every algorithm against those textbook answers and an independent simulator.
