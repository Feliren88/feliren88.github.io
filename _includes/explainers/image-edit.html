Remove part of an image and ask the network again

A trained network labels an image. Erase a region, let the gap fill from its surroundings, and see whether the label survives. Then let the page find which regions the chosen class depends on.

After Cabrera, Hohman, Lin and Chau, Interactive Classification for Deep Learning Interpretation (CVPR 2018 demo, MIT licence), which uses SqueezeNet and PatchMatch inpainting. Here the network is Tiny VGG from CNN Explainer, erased pixels are filled by harmonic (diffusion) inpainting, and the map is occlusion sensitivity after Zeiler and Fergus, Visualizing and Understanding Convolutional Networks (2014).
