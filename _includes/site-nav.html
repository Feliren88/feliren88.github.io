{%- comment -%} Renders the navigation links from _data/navigation.yml. {% include site-nav.html %} Marks the item matching the current page with `is-active`. An item owns: * its own href, exactly -- so `/` matches the homepage; * anything beneath its own href -- so /usecases/some-project/ lights up Use Cases. `/` is excluded from this test, or it would claim every page; * any prefix listed under `owns:` in the data file -- so a long-form note at its own top-level URL still lights up Writings. Later items win, which only matters if two hrefs nest. A page that matches nothing falls back to the first item. That covers the unlisted syllabus pages, /project/, /cv/ and 404, and it reproduces what the JavaScript did before this was resolved at build time: its lookup ended in `return item ? item.page : '/'`, and `/` is About. Removing the fallback would leave those pages with no current-page indicator at all, which is a visible change rather than a refactor. Active state is resolved here, at build time, rather than in JavaScript. A reader with JavaScript disabled still sees where they are, and there is no frame where the wrong item is highlighted. Because the footer renders through this same file, its current-page link now carries `is-active` too, which it did not before: the old JavaScript scoped that class to `nav.nav`. Nothing styles it, since the only rule is `.nav a.is-active` and the footer's class is `footer-nav`. Worth knowing before adding any rule that selects `a.is-active` without a parent scope, because it would start styling the footer as well. {%- endcomment -%} {%- assign nav_active = '' -%} {%- for item in site.data.navigation.primary -%} {%- if page.url == item.href -%} {%- assign nav_active = item.href -%} {%- else -%} {%- unless item.href == '/' -%} {%- assign head = page.url | slice: 0, item.href.size -%} {%- if head == item.href -%}{%- assign nav_active = item.href -%}{%- endif -%} {%- endunless -%} {%- for prefix in item.owns -%} {%- assign head = page.url | slice: 0, prefix.size -%} {%- if head == prefix -%}{%- assign nav_active = item.href -%}{%- endif -%} {%- endfor -%} {%- endif -%} {%- endfor -%} {%- if nav_active == '' -%} {%- assign nav_active = site.data.navigation.primary.first.href -%} {%- endif -%} {%- for item in site.data.navigation.primary -%} {% if item.href == nav_active %}{{ item.label }}{% else %}{{ item.label }}{% endif %} {% endfor -%}
